# Leo — собственная языковая модель с нуля

Здесь весь код, чтобы обучить свою модель **без чужих API и без чужих весов**:
токенизатор → архитектура (Llama-подобный трансформер) → предобучение → обучение диалогу → сервер.
Сайт Leo AI подключается к нему без изменений кода: меняются только переменные окружения.

> **Честно о результате.** Модель, обученная с нуля на ваших данных и бесплатных GPU, будет
> маленькой (15–110 млн параметров). Она не сравнится с Claude, GPT или Gemini — их обучают
> на тысячах видеокарт. Качество зависит от количества и качества текста. Эта папка даёт рабочий
> фундамент; насколько «умным» станет Leo — решают данные и вычисления.
>
> Код написан и проверен только на уровне синтаксиса: в среде, где он создавался, нет PyTorch и
> видеокарты. Поэтому **первым делом запустите `python smoke_test.py`** (30 секунд).

## Размеры модели

| preset | параметров | контекст | где обучать |
|---|---|---|---|
| `tiny` | ~15 млн | 512 | ноутбук (CPU, медленно) или бесплатный GPU |
| `small` | ~110 млн | 1024 | один GPU (например, Kaggle / Colab / аренда) |
| `medium` | ~370 млн | 2048 | мощный GPU, много часов |

Бесплатные GPU обычно дают Kaggle и Google Colab (с лимитами по времени). Проверьте текущие условия.

## С телефона (без компьютера)

Откройте в браузере блокнот Colab и запускайте ячейки по порядку:
<https://colab.research.google.com/github/harringtonov-cloud/leo.ai/blob/main/leo-model/Leo_Colab.ipynb>
(на телефоне включите «Версия для ПК» в меню браузера и выберите GPU в настройках среды).

## Шаги

```bash
cd leo-model
pip install -r requirements.txt
python smoke_test.py                      # 1. проверка: все строки OK
```

**2. Данные.** Нужен текст — чем больше и чище, тем лучше. Для пробы:
```bash
python prepare.py --hf roneneldan/TinyStories --max-docs 300000 --out data
# или ваши файлы:  python prepare.py --input папка_с_текстами/ --out data
```
Для кода и «умных» ответов нужны большие корпуса (веб-текст, код). Смотрите **лицензии** данных.
Это же создаёт токенизатор `data/tokenizer.json` (словарь 16 384 токена).

**3. Предобучение** (модель учится языку):
```bash
python train.py --preset tiny --max-steps 5000
python train.py --preset small --batch-size 16 --grad-accum 8 --max-steps 50000 --compile
python train.py --preset small --resume     # продолжить с чекпоинта
```
Следите за `val loss`: он должен падать. Чекпоинт — `out/ckpt.pt`.

**4. Обучение диалогу** (SFT). Нужен файл JSONL с беседами, формат — `examples/sft_sample.jsonl`
(три строки только для показа формата; для реального результата нужны тысячи диалогов):
```bash
python sft.py --data мои_диалоги.jsonl --epochs 3
```
Результат — `sft_out/ckpt.pt`. Учится только текст ответов ассистента.

**5. Запуск сервера** (совместим с форматом OpenAI):
```bash
LEO_API_KEY=придумайте-длинный-секрет python serve.py --host 0.0.0.0 --port 8000
```

**6. Подключение сайта.** Сервер должен быть доступен по HTTPS из интернета (Vercel не может
запускать модель сам): например, VPS с Caddy/nginx или Cloudflare Tunnel. Затем в Vercel
(Settings → Environment Variables), и Redeploy:

```
OPENROUTER_BASE_URL = https://ваш-домен/v1
OPENROUTER_API_KEY  = тот же LEO_API_KEY
MODEL_FAST          = leo
MODEL_GENERAL       = leo
MODEL_CODING        = leo
```

## Как это устроено
- `leo/model.py` — трансформер: RMSNorm, RoPE, SwiGLU, grouped-query attention, KV-кэш.
- `leo/tokenizer.py` — byte-level BPE, обучается на ваших данных; формат чата `<|user|> … <|end|>`.
- `prepare.py` → `train.py` → `sft.py` → `serve.py` — весь путь от текста до ответов в чате.
- `serve.py` держит одну генерацию за раз; для нагрузки нужен GPU и очередь/батчинг.

## Ограничения
- Нет проверки безопасности ответов и фильтров; модель может говорить глупости и неправду.
- Нет лимитов запросов на пользователя — держите ключ в секрете.
- Сайт не умеет «выполнять» код модели; кнопка запуска Python использует отдельный E2B-сандбокс.
